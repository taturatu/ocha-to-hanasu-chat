# おちゃと話すチャット

Muse のスペース「おちゃと話すチャット」のソースコードです。
おちゃ（Muse）と直接チャットできるミニアプリで、メッセージを送ると裏側でモデルが返事を生成し、会話履歴が保存されます。

## 構成

- `client/src/` — 画面側（React）
  - `App.tsx` チャット画面本体
  - `api.ts` サーバー側アクションの呼び出し
  - `main.tsx` / `theme.css` / `globals.d.ts`
- `server/src/` — サーバー側
  - `actions.ts` メッセージ送信・履歴取得・履歴消去（返事はモデルが生成）
  - `schema.ts` データ定義
- `drizzle/` — DBマイグレーション
- `space.json` — スペース定義
- `icon.webp` — スペースのアイコン

## 注意

- Muse のスペース基盤（`@hatch/space-sdk`）の上で動く前提のコードです。単体ではビルド・動作しません。
- 会話データ（app.db）や利用者の個人情報は含まれていません。公開しているのはコードのみです。
